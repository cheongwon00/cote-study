# 카펫 Lv2 [문제](https://school.programmers.co.kr/learn/courses/30/lessons/42842?language=java)

## 아이디어

- 가로 및 세로를 a,b라고 할 때 2a+2b-4=brown, (a-2)(b-2)=yellow가 성립함
- a+b와, ab값을 brown과 yellow 값으로 계산 후, a,b쌍을 순서대로 돌면서 확정

## 코드흐름

- a+b값과, ab값을 yellow,brown값으로 계산
- a값 하나만 정하면 b값은 자동으로 정해짐
- a를 하나씩 증가하며, a,b순서쌍을 검사하며 답을 확정
