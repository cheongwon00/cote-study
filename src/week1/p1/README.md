# 순위 검색 Lv2 [문제](https://school.programmers.co.kr/learn/courses/30/lessons/72412)

## 아이디어

- 일정점수이상? -> 이분탐색 lower bound
- 쿼리마다 필터링 -> 매 쿼리마다 전체 인원을 탐색해야하므로 비효율적 -> 지원자 조건을 가능한 쿼리 형식으로 미리 만들어놓고, 해시맵을 사용하면 최적화 가능

## 코드흐름

- 입력이 들어오면, 조건1,2,3,4에서 1포함/미포함,2포함/미포함, ... 등으로 미리 쿼리 쌍을 만들어놓고, 이를 key로 하고, value를 List로 점수들을 추가해줌 -> 해시맵 key마다 각 list들을 오름차순으로 정렬 -> 쿼리 검색 후, 이분탐색으로 lower bound를 찾아서, List의 size와 빼줌(인원수 구하기)

## 배운점

- 처음에는 조건대로, class를 하나 정의해서, 조건대로 filter를 해주었는데 시간초과 발생
- 일정 숫자 이상인 조건을보고 이분탐색인것을 떠올림
- 매 반복마다 모든 범위를 탐색해야한다면 -> 반대로 미리 만들어놓고 바로 접근가능한 방법이 있나 생각해보기
